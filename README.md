Este projeto foi desenvolvido como forma de aprendizado em Python e tem como objetivo consumir a API do Watchmode para realizar consultas de filmes.

O programa solicita ao usuário o nome do filme que deseja pesquisar, apresenta as opções encontradas e permite selecionar um título para consultar informações detalhadas, como ano de lançamento e sinopse.

Foi utilizado:

Python
Requests
python-dotenv
Watchmode API

A chave de acesso à API é armazenada em um arquivo `.env`, evitando que a credencial seja inserida diretamente no código-fonte.
